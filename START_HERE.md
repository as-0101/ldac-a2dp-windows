## 1. Mission and required acceptance
Adapt Bluetooth Classic headset support to Windows Server 2022 (build 20348) using the existing Server Bluetooth transport and Windows Audio infrastructure. Reference hardware: OPPO Enco Buds2 + Intel Bluetooth controller. A2DP Source/SBC to headset Sink UUID 0x110B is the first playback milestone; HFP Audio Gateway to headset Hands-Free UUID 0x111E is separately mandatory. LDAC is optional.

After **one pairing**, Windows Sound Settings must offer a usable headphone **render** endpoint and headset microphone **capture** endpoint belonging to the **same physical OPPO device**; correlate ContainerID, PnP ancestry, Bluetooth identity (not friendly names alone). In a real messenger call both directions must work **at the same time**: local user hears remote speech via OPPO, remote user hears the OPPO's built-in mic. Repeat after reconnect; confirm stereo A2DP before a call and recovery after; compare against the same Windows 10 scenario; repeat on another Classic headset and another Bluetooth adapter. Two logical audio endpoints are expected/allowed. Without real hardware, remote participant, and observed duplex, acceptance = **UNTESTED**, not passed.
